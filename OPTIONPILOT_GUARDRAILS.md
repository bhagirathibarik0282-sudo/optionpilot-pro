# OptionPilot Permanent Guardrails

Status language is restricted to **PROVEN / PARTIAL / NOT_PROVEN / BLOCKED**.

## Frozen business chain
Kite live-feed truth → Recorder continuity → Canonical archive → Deterministic engines → Candidate authority → Telegram/Dashboard → Forward outcomes → Historical calibration → Execution shadow → Real execution readiness.

## Non-negotiable rules
1. Merged code is never equivalent to working runtime proof.
2. Missing/stale/null critical data stays missing; never synthesize a business-safe value.
3. One candidate authority must feed recorder, Telegram, Dashboard and shadow execution.
4. SMC and Candle Context are interpretation layers, never independent voting families.
5. Candle Context is restricted to Displacement, Rejection, Failed Break, Compression→Expansion.
6. Historical reconstruction must be labelled RECOVERED_HISTORICAL and never mixed with LIVE_RECORDED truth.
7. Every scheduled recorder cycle must persist normalized rows and a full canonical runtime archive.
8. Replay must expose continuity, missing buckets and canonical coverage.
9. Same symptom surviving two bounded fixes triggers root-cause re-diagnosis; no third blind patch.
10. Research/backtest modules cannot mutate live verdict, Telegram or execution authority without a separately approved promotion.
11. No Railway AI Agent. No manual Railway/config/deploy mutation without explicit approval.
12. No parameter can be called complete unless the coverage manifest shows storage, replay, consumer and runtime-proof evidence.

## Required live-market parameter families
- Kite/session/WebSocket/token freshness
- Spot structure: Open, Gap, VWAP, PDH, PDL, Day High/Low
- SMC interpretation
- Candle Context: Displacement, Rejection, Failed Break, Compression→Expansion
- Futures: LTP, basis, OI, volume, lead/lag, basis z-score
- Heavyweights and sectors with 3m/6m/15m/30m response windows
- India VIX
- CE/PE premium pair and opposite-side behaviour
- Exact contract identity
- OI/PCR, PCR velocity, call/put walls, build/shed/migration
- Multi-DTE
- IV, term structure, skew
- Greeks and Greeks-adjusted premium residual
- Depth/order-flow imbalance, spread, microprice, liquidity/executability
- Buyer/Seller, Intraday/Multiday/Expiry business views
- Candidate ranking and stars
- Market DNA / transition timing
- Telegram meaningful-change and dedup
- T0 freeze, T+3/6/15/30, MFE/MAE, rank, percentile, regret
- Historical edge, execution shadow, exclusivity, dynamic SL/TSL, profit locking

## Promotion rule
A component may be marked PROVEN only when the machine-readable coverage manifest includes concrete runtime evidence. CI must fail if PROVEN is declared without evidence.
