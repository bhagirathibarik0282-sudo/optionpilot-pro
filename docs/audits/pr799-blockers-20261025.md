## B2 selected next

Both source queries use `idx_app_state_log_kind_created`, with index condition
on kind only. Symbol and source date/time are residual filters. Read-only
catalog deployment `4c2453a1-184e-482d-9dac-d8c7b3b321aa` confirmed only that
index plus `app_state_log_pkey` on this table. Total relation size was
1,631,887,360 bytes (including indexes/TOAST), index size 93,487,104 bytes;
these are this table's sizes, not the whole database or remaining disk space.
The live-row statistic 645,413 is an estimate, not a counted archive inventory.

Do not add a created_at time fence: late-imported archives could disappear.
No index or schema change was made. A candidate must preserve late imports,
offset timestamp handling, exact snapshot joins, duplicates and truth markers.
Any index proposal also needs available disk headroom and build-lock review.
The observed 26.03s canonical read is not a measured speedup or proof that one
specific physical mechanism accounts for all latency.
