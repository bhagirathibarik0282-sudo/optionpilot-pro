# Chapter reading context

Each Market Book chapter starts with a short Odia reading order and four relevant measured parameters, rather than a universal interpretation or score. OI/walls starts with exact-contract OI, full PCR, wall strikes and premium; VIX starts with VIX, Spot, premium and PCR; sectors starts with heavyweight and sector quote breadth. All twelve visible chapters are covered, plus the retained expiry chapter definition.

Facts show the selected recorded index/session/window. Expand each parameter for previous/current values and exact timestamps. CE and PE expiry/strike identities stay independent. OI retains source units, missing is a dash, PCR requires the existing qualified full-chain provenance, VIX is not summed across index recordings, breadth excludes invalid/missing percentages and is labelled unweighted versus previous close. Cash retains its own EOD session date. Latest endpoint context is explicitly not historical event-time context.

A separate LIVE context strip in the chapter header shows selected-index full PCR coverage, exact option OI, VIX and sector breadth using the existing live view's stream. It identifies live expiry/strike scope and independent timestamps; live selection can differ from recorded chapter selection. It neither feeds historical calculations nor grants trading authority. Pausing, disconnecting, hiding or stalling the existing stream clears the shared live values. No additional stream, broker request, storage or configuration change is introduced. Existing replay, chart controls, RAG and candidate logic are unchanged.

The reading grid uses four columns on wide screens, two at medium widths and one on small phones, with large values and expandable timestamp detail. The existing mobile chapter stacking is retained.

Validation covers chapter-specific parameter order, source labels, separate identities/dates, missing/provenance handling, invalid breadth exclusion, escaping, stale/disconnected live data and serialized navigation through every visible chapter without extra requests. Actual browser visual verification remains pending.
