# Dashboard and premium workspace

The DATA observation terminal now has a navy workspace shell, a shared live index/VIX ticker and all 13 chapters. Chapter visibility is remembered in this browser. The existing recorded views, replay and reading controls remain available. The live feed detail is collapsed initially.

Premium Behaviour provides independent CE/PE strikes, 3/5/7 near-ATM or all strikes, multiple expiry choices, DTE groups, 1/3/5/15/30/45/75/125-minute reaction windows and previous-close comparison. Cards and tables show exact contract identity, premium, change, level reaction and observation interval. PDH/PDL, Fibonacci pivots, OI, IV and live PCR/VIX/futures context are individually selectable. Twelve contracts are shown per page; reaction filtering and rising/falling counts apply to that page for live data. The watchlist count covers the server-side index/expiry/DTE/strike filters.

`GET /api/research/dashboard-live/premiums` reads the existing display-only Kite token cache once a second while this chapter is visible. It adds no broker connection, provider request, database table, recorder writes or execution authority. Filters: `symbol`, `side`, `expiries` (up to four comma-separated dates), `ceStrike`, `peStrike`, `nearby` (1/2/3 strikes each side of ATM), `minDte`, `maxDte`, `offset`, `limit` (at most 120). Disconnected, stale or wrong-session numeric values are withheld. Full expiry omissions remain explicit. Shared live context continues through the existing stream.

Live samples retain actual source and receipt times, with bounded per-contract history (240 contracts, up to 130 samples each). Baselines precede the target time by at most 60 seconds and expose their actual time. Recorded baselines must match exactly. These are reaction windows over sampled prices. Contradictory same-time duplicates are quarantined. Missing samples or gaps above three minutes clear retained event timestamps. PDH/PDL references require the same exact session/contract; FIB requires an earlier exact-contract 15:30 H/L/endpoint record. No candles or indicator readings are synthesized.

Validation: 174 tests in the full dashboard CI suite passed, together with the production proof checks; dashboard module bundled successfully. A DOM interaction check used recorded 13 October 2026 data across all 13 chapters, independent filters, cards/table, FIB, chart opening and chapter customization. Browser pixel inspection and an open-market live production session remain to be verified after approval and deployment.


Live mode is the opening default on every reload; an earlier Recorded selection cannot silently restore historical figures. Quotes are projected again at display time, not merely accepted from a LIVE label. The browser uses the server clock plus elapsed delivery time, revokes premium/OI/bid/ask/volume/previous-close values if delivery stalls beyond three seconds, and rechecks each source timestamp. PCR retains its explicitly labelled 1/3-minute snapshot cadence and requires complete exact-expiry OI coverage. Futures and VIX have separate source timestamps. PDH/PDL/FIB remain dated reference levels. Bid/ask and volume have their own optional display layer. IV is never copied from a recorded session into a live row.

A controlled live DOM check verified changes in premium, OI, bid, ask and volume, live default restoration and clearing values during a hung request. An open-market production session remains unverified before deployment.
