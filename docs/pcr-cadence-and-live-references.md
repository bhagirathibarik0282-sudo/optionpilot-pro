# PCR snapshots and chart references

Each live index card has its own PCR update selector: **1 min** (default) or **3 min**. Spot, exact CE/PE prices, futures and participation keep using the existing stream. PCR is labelled a periodic snapshot with original exchange timestamps and checked time, not a millisecond OI claim. The display cadence is browser-local, reset on a new view; it does not modify the recorder or account-wide broker cadence.

A shared display-only collector checks the existing subscribed whole-expiry inventories once per minute per server process. Up to 3,000 tokens means no more than six sequential `/quote` requests per cycle, max 500 instruments per request, with 1.1-second spacing. It runs only while the display feed is enabled, market is open and socket is OPEN. No overlapping cycles or immediate error retries. A 429/error ends that cycle. Other existing account requests can still encounter rate limits; this does not claim an account-wide rate limiter.

Each exact instrument key and token must match; zero OI is valid. Missing, negative/non-numeric OI, wrong identity, wrong-session/future/stale exchange timestamps and >30s source skew prevent a full snapshot. Original timestamps are never replaced with receipt time. REST results do not enter the tick store or any trading consumer. Failure publishes incomplete coverage rather than silently carrying a prior cycle forward. Results expire at 90s if collection stops. Bounded missing/stale/invalid diagnostics help audit remaining gaps. The API retains the existing separate raw WebSocket `fullPcr` fields and adds `pcrSnapshot` with explicit REST provenance.

The 3min view holds its last qualified snapshot between scheduled samples and shows that snapshot's time/coverage. Any new incomplete attempt or socket failure immediately withholds its displayed number. Gaps break PCR lines. Expiry/strike changes clear old samples; changing cadence resets that index's PCR chart. No browser-triggered broker calls or extra SSE connections.

Per-series **15m H/L** switches reuse the five exact recorded 09:15–09:27 samples, available after 09:30. They are sampled references, not official candle extremes. **FIB P/R/S** switches on Spot/CE/PE reuse the existing previous recorded session pivots with exact 15:30 endpoint. No Fibonacci levels are invented for PCR. Reference source times are displayed; missing references stay unavailable.

The existing Market Book publishes loaded references through an in-page event, with no extra historical request. Live charts require the same selected trading date, index, expiry, strike and side; changing only the live selector cannot borrow another contract's references. Load the matching recorded selection and earlier sessions below when references are unavailable. Switches are independent by index and series.

No database, recorder cadence, candidate authority, Telegram or order change. Deployment enables these additional bounded quote requests wherever the existing DASHBOARD_LIVE_ENABLED flag is already true; review/approval before merge is required. Production complete-PCR acceptance and actual phone visual QA remain unproven until rollout.
